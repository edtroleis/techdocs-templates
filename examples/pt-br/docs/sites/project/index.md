# Novo provedor de cartão

## Objetivo

Levar todos os pagamentos com cartão para o provedor novo até o fim do trimestre, reduzindo em 20% o custo por
pagamento e deixando abaixo de 1% as recusas causadas pelo provedor.

## Situação

| Início     | Fim previsto | Situação |
| ---------- | ------------ | -------- |
| 2026-07-01 | 2026-12-15   | No prazo |

## Pessoas

| Papel        | Quem                             |
| ------------ | -------------------------------- |
| Responsável  | Time de Pagamentos               |
| Patrocinador | Diretoria de Comércio            |
| Times        | Pagamentos, Checkout, Financeiro |
