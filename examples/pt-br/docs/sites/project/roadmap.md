# Cronograma

## Fases

| Fase        | O que entrega                                            | Datas           | Situação     |
| ----------- | -------------------------------------------------------- | --------------- | ------------ |
| Descoberta  | A RFC aprovada e o contrato assinado                     | 1/jul – 15/ago  | Concluída    |
| Construção  | Os dois provedores atrás de uma interface, 1% do tráfego | 16/ago – 31/out | Concluída    |
| Implantação | 100% do tráfego no provedor novo, o antigo desligado     | 1/nov – 15/dez  | Em andamento |

## Marcos

- 10/nov: 25% dos pagamentos no provedor novo; o Financeiro confere a primeira fatura
- 1/dez: 100% dos pagamentos; o provedor antigo só para estornos
- 15/dez: termina o contrato antigo

## Riscos

| Risco                                                      | Impacto | O que fazemos                     |
| ---------------------------------------------------------- | ------- | --------------------------------- |
| Estornos de pagamentos antigos precisam do provedor antigo | Médio   | Mantê-lo para estornos até março  |
| Black Friday durante a implantação                         | Alto    | Congelar em 50% de 20/nov a 1/dez |

## Mudanças neste cronograma

- 12/out: implantação uma semana depois, para esperar a correção do 3-D Secure do provedor
