# Suporte e SLAs

## Como falar com o time

| Para                        | Onde                                |
| --------------------------- | ----------------------------------- |
| Dúvidas                     | `#commerce-platform`                |
| Pedidos e bugs sem urgência | Um chamado no portal, fila COMMERCE |
| Pagamentos falhando         | Acionar o plantão de Pagamentos     |

## Níveis de serviço

| Recurso           | Disponibilidade | Primeira resposta |
| ----------------- | --------------- | ----------------- |
| Pagamentos        | 99,95%          | 15 minutos, 24x7  |
| Notas fiscais     | 99,5%           | 4 horas úteis     |
| Análise de fraude | 99,0%           | 1 dia útil        |

## Janelas de manutenção

Terças, das 2h às 4h (UTC). O trabalho planejado é avisado no `#commerce-platform` dois dias antes; os
pagamentos continuam funcionando.

## Situação

A página de status em `status.internal.example.com/commerce` mostra os incidentes em andamento e os últimos 90
dias.
