# Como pedir acesso

## Quem pode usar a plataforma

- Qualquer time com um serviço no catálogo que vende para clientes
- O serviço precisa ter dono e centro de custo no catálogo antes do pedido

## Como pedir

1. No portal, abra **Acessos → Plataforma de Comércio**.
2. Escolha o serviço e os recursos: Pagamentos, Notas fiscais, Análise de fraude.
3. O acesso ao sandbox é imediato; o de produção é aprovado pelo time de Pagamentos em até dois dias úteis.

## O que você recebe

- Um cliente da API de Pagamentos, com o segredo no cofre
- O serviço no grupo `commerce-users`, para os painéis

## Tirar o acesso

Quando um serviço é desligado, marque-o como desligado no catálogo: o acesso sai na noite seguinte.
