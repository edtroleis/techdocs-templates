# Plataforma de Comércio

O que a Plataforma de Comércio dá aos times que vendem alguma coisa, para nenhum deles construir sozinho
pagamentos, notas fiscais ou análise de fraude.

## O que ela oferece

| Recurso           | O que você recebe                               | Situação |
| ----------------- | ----------------------------------------------- | -------- |
| Pagamentos        | Cobranças e estornos de cartão por uma API só   | Estável  |
| Notas fiscais     | Nota emitida e enviada depois de cada pagamento | Estável  |
| Análise de fraude | Uma nota de risco para cada pedido              | Beta     |

## Por onde começar

1. Peça acesso, como explica [Como pedir acesso](access.md).
2. Siga o [golden path](../../tutorials/golden-path.md) para criar um serviço que vende.
3. Procure no [glossário](../../reference/glossary.md) os termos que não conhece.

## O que ela não faz

- Preços e promoções ficam com cada time de produto
- O atendimento responde aos clientes; a plataforma responde aos times

## Quem cuida

O time de Pagamentos. Veja [Suporte e SLAs](support.md).
