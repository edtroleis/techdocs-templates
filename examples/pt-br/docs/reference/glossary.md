# Glossário

Termos usados nesta documentação, em ordem alfabética.

## C

### Captura

Pegar o dinheiro que uma autorização reservou. O Serviço de Pagamentos autoriza e captura num passo só.

### Chave de idempotência

Um valor que o cliente manda para que repetir uma requisição não cobre duas vezes. Veja o [ADR 0003](../explanation/adr.md).

## P

### Provedor

A empresa externa que fala com as bandeiras de cartão por nós.

## W

### Webhook

Uma chamada que o provedor faz para nós quando um pagamento muda de estado.
