# Rituais do time

Como o time de Pagamentos trabalha semana a semana.

## Resumo

Planejamento às segundas, uma daily curta e uma review a cada duas sextas.

## Conteúdo

| Ritual       | Quando                               | Duração | Para quê                      |
|--------------|--------------------------------------|---------|-------------------------------|
| Planejamento | Segunda 10:30                        | 45 min  | Escolher o trabalho da semana |
| Daily        | Todo dia 9:45                        | 15 min  | Destravar uns aos outros      |
| Review       | Sexta, semana sim, semana não, 15:00 | 30 min  | Mostrar o que foi entregue    |
| Retro        | Última sexta do mês                  | 45 min  | Melhorar o jeito de trabalhar |

As reuniões são opcionais para quem está de plantão.
