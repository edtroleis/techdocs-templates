# Payments Service (examples)

These pages show what each template of the [TechDocs Editor](https://marketplace.visualstudio.com/items?itemName=edtroleis.techdocs-editor)
looks like when it is filled in. They describe a fictional service, the **Payments Service**, that charges
customers' cards through an external provider.

The pages follow [Diátaxis](https://diataxis.fr/), which sorts documentation by what the reader needs:

| Category      | The reader wants to       | Pages here                                                                                                                                                                                                                               |
|---------------|---------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Tutorials     | Learn by doing, from zero | [Your first payment](tutorials/tutorial.md), [Onboarding](tutorials/onboarding.md), [Golden path](tutorials/golden-path.md)                                                                                                              |
| How-to guides | Get a known task done     | [Rotate the API key](how-to-guides/guide.md), [Refund a payment](how-to-guides/how-to.md), [Runbook](how-to-guides/runbook.md), [Troubleshooting](how-to-guides/troubleshooting.md)                                                      |
| Reference     | Look something up         | [Service home](reference/service-home.md), [Operations](reference/operations.md), [API](reference/api-reference.md), [Wiki page](reference/wiki-page.md), [Release notes](reference/release-notes.md), [Glossary](reference/glossary.md) |
| Explanation   | Understand why            | [Architecture](explanation/architecture.md), [ADR](explanation/adr.md), [Postmortem](explanation/postmortem.md), [RFC](explanation/rfc.md)                                                                                               |

Everything here is made up: names, numbers, links and people.
