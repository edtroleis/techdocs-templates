# Glossary

Terms used in this documentation, in alphabetical order.

## C

- **Capture**: Taking the money that an authorization reserved. The Payments Service authorizes and captures
  in one step.

## I

- **Idempotency key**: A value the client sends so that repeating a request does not charge twice. See
  [ADR 0003](../explanation/adr.md).

## P

- **Provider**: The external company that talks to the card networks for us.

## W

- **Webhook**: A call the provider makes to us when a payment changes state.
