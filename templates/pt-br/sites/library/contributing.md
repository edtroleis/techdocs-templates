# {{title}}

Mudanças de outros times são bem-vindas. Esta página diz como fazer uma entrar
rápido.

## Antes de começar

- Abra uma issue para discutir qualquer coisa maior que uma correção, antes de
  escrever o código
- Confira se ninguém já está trabalhando nisso

## Rodar na sua máquina

```bash
git clone <repositório>
make install
make test
```

## Enviar uma mudança

1. Crie um branch a partir da `main`.
2. Acrescente testes para o que mudou e atualize esta documentação.
3. Abra um pull request descrevendo o problema e a solução.
4. Um mantenedor revisa no prazo combinado.

## Publicar

Só os mantenedores publicam versões. Uma mudança aceita sai na próxima versão.
